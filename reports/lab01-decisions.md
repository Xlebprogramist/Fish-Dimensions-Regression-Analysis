## Удаление аномальной строки (Weight = 0)

- **Что:** строка `Roach` с `Weight = 0.0` (исходный индекс 40) удалена из `assets/data/Fish.csv`.
- **Почему:** физически невозможно — рыба не может весить ноль при нормальных геометрических размерах (Length1=19, Length2=20.5, Length3=22.8, Height=6.48, Width=3.35).
- **Тип аномалии:** ошибка измерения или ввода, не выброс. Отличается от «крупная рыба» — там значение правдоподобно.
- **Альтернативы:**
  - оставить с флагом `is_weight_anomaly` — отклонено, одна строка не оправдывает новый столбец;
  - восстановить вес по регрессии длина→масса — отклонено, добавляет синтетику;
  - оставить как есть — отклонено, портит целевую переменную.
- **Проверка:** `assets/data/Fish.csv` содержит 158 строк данных, `min(Weight) > 0`.
- **Влияние:** одна строка из 159 (<0.7%), распределение целевой переменной не меняется значимо.
